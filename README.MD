# YouTube Video Chat Assistant 🎥💬

A full-stack AI-powered application that allows you to chat with YouTube video content. Process any YouTube video with transcripts and have intelligent conversations about its content using Groq AI.

## 🌟 Features

### Backend (FastAPI)
- 🎬 **YouTube Transcript Extraction** - Automatically fetch captions from any YouTube video
- 🧠 **AI-Powered Conversations** - Groq LLM integration for intelligent responses
- 💾 **Vector Search** - FAISS-based semantic search for relevant content retrieval
- 📄 **PDF Export** - Export chat conversations as downloadable PDFs
- 🔍 **Smart Chunking** - Intelligent text splitting for optimal AI processing
- 🚀 **High Performance** - Async FastAPI with efficient processing

### Frontend (Next.js + TypeScript)
- 🎨 **Modern UI** - Clean, responsive design with Tailwind CSS
- 💬 **Real-time Chat** - Interactive chat interface with message history
- 📱 **Mobile Friendly** - Fully responsive across all devices
- 🎯 **Type Safety** - Full TypeScript implementation
- ⚡ **Fast Performance** - Next.js 14 with App Router
- 📊 **Usage Analytics** - Track AI usage and limits
