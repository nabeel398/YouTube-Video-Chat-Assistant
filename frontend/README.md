# YouTube Video Chat Assistant - Frontend

A Next.js + TypeScript frontend for chatting with YouTube video content using AI.

## Features

- 🎥 Process YouTube videos with transcripts
- 💬 AI-powered chat with video content
- 📄 Export chat conversations to PDF
- 🎨 Modern UI with Tailwind CSS
- 🔒 Type-safe with TypeScript

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Backend**: FastAPI (separate repository)
